# RE-GEO Studio 🌋🏛️

**RE-GEO Studio** është një aplikacion ueb i zhvilluar me **Django** dhe **Bootstrap 5**, i fokusuar në ofrimin e shërbimeve inxhinierike gjeoteknike, analizave hidrogjeologjike dhe vlerësimit të riskut sizmik sipas standardeve evropiane (**Eurocode 8 - EC8**).

---

## 🚀 Veçoritë Kryesore

* **Moduli Interaktiv i Riskut Sizmik & Gjeologjik:** Vlerësim dinamik në kohë reale i parametrave sizmikë (PGA, kategoria e truallit, rreziku i likuidimit) bazuar në rajonet e Shqipërisë.
* **Arkitekturë Modulare Django:** Organizim i pastër i aplikacioneve (`core`, `projects`, `services`).
* **Ndërfaqe Responsive (UI/UX):** Ndërtuar me Bootstrap 5 me dark mode moderne dhe navigim të konsoliduar.
* **Përputhshmëri me Eurocode 8:** Klasifikim i saktë i truallit (A, B, C, D, E) dhe rekomandime për bazamentin e strukturave.

---

## 🛠️ Teknologjitë e Përdorura

* **Backend:** Python 3, Django 5.x
* **Frontend:** HTML5, CSS3, JavaScript (ES6), Bootstrap 5
* **Version Control:** Git & GitHub
